# Model

Het staat model voor digitale tuintjes welke bij 'Het web is voor iedereen' door studenten worden gemaakt.

## Learning Log

### 7 sept - werkles

Artikel: The garden and the stream: A Technopastoral
De schrijver wil de lezers overtuigen dat de Garden beter is omdat het persoonlijker is, je kan artikelen uploaden die jij interessant vindt. Slechte artikelen aanpassen/ herschrijven. Je kan op elk moment dingen aan je Digital garden toevoegen.

1. Een digital garden is een verzameling van bestanden die je bij elkaar hebt gezocht, hier plaats je bijv. notities bij en je kan teksten aanpassen of herschrijven. Een normale website is vaker geschreven als een blog en een digital garden is persoonlijker en nooit af, je kan altijd dingen toevoegen.
2. Een website is "Webby" als het makkelijk toegankelijk is, duidelijke hiërarchie, als het zich aanpast aan elk scherm en light/dark en als het geen afleiding geeft op de achtergrond. Zelf vond ik de website Paavandesign uit de opdracht mooi en netjes gemaakt.
3. Voor mijn digital garden had ik het idee om inspiratie te geven over solo activiteiten of groepsactiviteiten indoor/ outdoor, en dan gaat het bijv. over creatieve dingen, sporten, actief, films/series en hotspots. Ik ga dit doen a.d.h.v. mijn interesses.


### 4 sept - deep dives

Deep dive Praktische CSS:
Bij deze deep dive heb ik geleerd hoe ik met basic CSS een lelijke html pagina mooi kan maken, een aantal CSS selectors waarmee ik html kan vormgeven en een simpele manier van een light-dark switch.

Deep dive CSS: fonts met kleur en effecten:
Bij deze deep dive heb ik geleerd hoe ik lettertypes in mijn website kunt gebruiken met web-safe fonts en met @font-face en hoe ik tekst met properties kan vormgeven.


### 2 sept - deep dives

Deep dive HTML & CSS Basics:
Bij deze deep dive heb ik geleerd hoe HTML en CSS samen gebruikt worden, hoe je nar bestanden in mapjes verwijst en hoe ik aanpassingen publiceert op het web via mijn repository.

Deep dive Interactie: MMD, micro-interacties, forms:
Bij deze deep dive had ik een herhaling over micro interacties en het Multi model design. Ook heb ik geleerd over formulieren en tot slot heb ik een formulier gemaakt voor het restaurant Wok to Walk.


### 31 aug - Kickoff
1. Een source hosting platform is een platform waar je model van websites op kan delen en van anderen hun codes kunt bekijken, ik heb zelf voor Github gekozen.
2. Ik heb voor mijn naam gekozen omdat de website over mijn werk gaat. Ik heb bij transIP een domeinnaam gekocht, daar moest ik IP adressen invullen en een CNAME, vervolgens heb ik die naam in Github toegevoegd.
3. Als ik aanpassingen aan mijn htmlpagina heb gemaakt, moest ik naar source control, daar moet ik een message indienen en dan op commit & sync klikken.
